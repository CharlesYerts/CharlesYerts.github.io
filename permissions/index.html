系统权限信息清单不申请的权限如何控制技术性本地访问

1. 系统权限

首次启动时，selfo 会先展示《隐私政策》和《用户协议》。只有你点按“同意并继续”后，selfo 才会请求照片读写权限；点按“暂不”不会发起照片权限请求。

权限使用场景能否拒绝拒绝或限制后的影响
照片读写访问
PhotoKit .readWrite		读取、预览、播放、扫描和分组媒体；创建及维护“selfo 收藏”；确认收藏与删除。可以核心整理需要“完全访问”。拒绝或只提供有限访问时，核心功能不可用；法律与订阅页面仍可查看。

iOS 只显示一次照片读写授权，不是 selfo 分别申请“读取权限”和“写入权限”。selfo 会在真正需要时使用该授权范围内的系统能力。

3. 当前不申请的权限

selfo 当前不申请：

  • 设备定位或后台定位；
  • 相机、麦克风；
  • 通讯录、日历、提醒事项；
  • 通知；
  • 蓝牙、本地网络；
  • 健康或运动数据；
  • 广告标识符和 App Tracking Transparency 追踪权限。

读取媒体文件中已有的拍摄坐标不等于申请设备定位权限。

4. 如何控制这些信息

  • 在 iOS 设置中调整或撤回 selfo 的照片访问；
  • 在待处理页撤销尚未确认的收藏或删除标记；
  • 从“selfo 收藏”移除相册成员关系而不删除原件；
  • 在 Apple Photos 的“最近删除”中管理系统已删除媒体；
  • 删除 selfo 以清除大部分 App 本地记录；
  • 通过 Apple 账号管理订阅；
  • 通过 隐私邮箱请求处理支持沟通信息。

5. Required Reason API

selfo 的 Apple 隐私清单声明不进行追踪、没有声明收集的数据类型。App 使用 UserDefaults 保存本地偏好，并读取系统启动时间用于时序或性能相关逻辑；这些访问按照 Apple 的 Required Reason API 规则声明，不用于识别、画像或跨 App 追踪用户。

更完整的处理规则见《隐私政策》。
