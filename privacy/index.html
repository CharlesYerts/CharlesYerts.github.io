隐私政策

1. 主体与适用范围

selfo 由个人开发者叶尔特斯·拜布提汗提供。在适用法律下，该个人开发者是本政策所述、由开发者决定处理目的和方式的信息处理主体。

本政策适用于 selfo iOS App、通过本页面提供的公开支持渠道，以及 selfo 官方网站。selfo 当前不提供自有账号系统，不要求登录，也不运行由开发者控制的照片或视频云端存储服务。

2. App 处理的信息

2.1 照片、视频与媒体元数据

在你授予照片读写访问后，selfo 会在授权范围内读取照片、视频、截图、录屏和 Live Photo，用于展示、播放、扫描、比较、分组和整理。核心图像与视频分析在设备上完成，不会把媒体内容上传到开发者控制的 selfo 服务器。

为了展示信息与完成整理，selfo 可能读取媒体的系统资源标识符、原始文件名、创建和修改时间、媒体类型、尺寸、时长、文件大小、相册归属，以及文件已有的拍摄设备、镜头、光圈、曝光、ISO、焦距等 EXIF 元数据。

2.2 媒体内嵌位置

selfo 不申请设备定位权限。如果媒体本身包含拍摄坐标，selfo 可能读取该坐标。当你查看地点名称或地图预览，或主动选择在 Apple 地图中打开媒体位置时，坐标可能通过 MapKit 交给 Apple Maps 服务，用于反向地理编码、地图快照加载或打开地图。selfo 不将坐标另行持久化到开发者服务器；地点解析结果与地图缓存仅作临时展示。

2.3 本地整理数据

selfo 会在设备本地保存继续使用所需的数据，包括：

  • 待收藏、待删除、已跳过、已完成和当前整理进度；
  • 相似照片组、截图与录屏、较大文件、颜色主题等可重新生成的扫描结果；
  • 媒体资源标识符或用于去重的摘要，以及按用户本地自然日记录的免费额度状态，包括当日预占、已使用和跨日待确认标记；
  • 整理足迹，例如日期、处理数量、估算释放空间和跳过数量；
  • 语言、视频声音、所选相册、信息面板和教学进度等设置。

2.4 订阅权益

如果你购买 selfo Pro，付款、续订、取消和退款由 Apple 处理。selfo 通过 StoreKit 读取产品标识符、权益是否有效、到期和交易状态，用于展示方案、解锁功能及恢复购买。selfo 不接收你的银行卡号、完整付款凭证或 Apple ID 密码。

2.5 支持沟通

当你主动发送邮件时，我们会处理你的邮箱地址、邮件正文、附件，以及你选择提供的设备型号、iOS 版本、App 版本、截图或日志，仅用于回复、排查问题、处理隐私请求和保留必要争议记录。请勿发送与问题无关的私密照片、身份证件、支付卡信息或密码。

3. 权限与用户选择

selfo 当前仅请求 iOS 的照片读写访问。核心整理流程需要“完全访问”；拒绝或只提供有限访问时，核心功能可能无法使用，但法律页面和订阅说明仍可查看。

创建和维护“selfo 收藏”普通相册、把原始媒体加入该相册，以及执行确认删除都需要相应照片权限。“selfo 收藏”不是 Apple 照片的爱心状态，加入相册不会复制或移动原件。

selfo 不申请相机、麦克风、通讯录、日历、设备精确定位、后台定位、蓝牙、健康数据、通知或广告追踪权限。你可以随时在 iOS 设置中调整照片访问，或删除 App 以清除大部分本地数据。

4. 系统服务与接收方

selfo 不出售个人信息，不为跨情境行为广告共享个人信息，也未接入广告、第三方统计、归因、社交登录或崩溃上报 SDK。为提供实际功能，可能涉及：

  • Apple Photos / PhotoKit / iCloud Photos：读取和修改你授权的系统图库；原件是否由 iCloud 下载取决于你的 Apple 设置和图库状态。
  • Apple StoreKit / App Store：提供商品信息、处理购买与账单、判断订阅权益及恢复购买。
  • Apple Maps / MapKit：当展示拍摄地点名称或地图预览，或你主动选择在 Apple 地图中打开媒体位置时处理媒体内嵌坐标。Apple 表示，在中国使用 Apple Maps 时，地图服务由高德软件有限公司（Amap Software Co., Ltd.）提供。
  • DGCharts：随 App 本地打包，用于绘制统计图表，不用于收集或传输个人信息。
  • Google / Gmail：当你发送支持邮件时，邮件内容由你使用的邮件服务商及 Gmail 处理。

上述 Apple 服务受 Apple 隐私政策约束，Apple Maps 的具体说明见 Apple Maps 与隐私；支持邮箱相关处理还受 Google 隐私权政策约束。

5. 保存期限与安全

  • 媒体内容保留在系统图库中，期限由你和 Apple 的设置决定。
  • 整理记录、扫描缓存和设置通常保留到你在 App 内清除相关记录、删除 App 或系统清理 App 数据为止。
  • 当天已使用的免费额度在用户本地自然日切换时自动重置。前一日仍未确认的预占项目会保留为可继续确认且不占新一天额度的本地记录，直到你撤回或确认，或相关记录、App 数据被清理。
  • 地点名称和地图预览缓存仅在运行期间或系统缓存范围内临时存在。
  • 支持邮件仅在处理请求、合理跟进以及必要安全或争议记录所需的最短期限内保存；目的实现后会删除或匿名化，适用法律要求继续保留的除外。你也可以请求提前删除。
  • Apple、GitHub、Google 等服务商按各自政策保存其控制的数据。

我们采用与个人开发者规模和处理风险相适应的措施，包括尽量减少数据、默认本地处理、使用系统权限边界，以及不设置开发者控制的媒体上传后端。但任何电子存储或传输方式都无法保证绝对安全。

6. 你的选择与权利

你可以通过 iOS 设置调整照片访问、在 selfo 中撤销尚未确认的整理标记、删除 App 清除大部分本地记录，并通过 Apple 账号管理订阅。

在适用法律规定的范围内，你可以请求查阅、复制、更正、补充、删除或限制由开发者控制的个人信息，撤回同意，或要求说明处理规则。由于 selfo 当前没有自有账号，因此不存在 selfo 账号注销流程；如果未来增加账号，我们会提供相应删除入口。

我们不出售个人信息，也不为跨情境行为广告共享个人信息。适用的美国州隐私法赋予你额外权利时，我们会依法处理。无论如何，你都可通过邮箱申请查阅、更正或删除由我们控制的支持沟通信息。我们不会因你依法提出请求而进行歧视性对待。

7. 跨境与境外处理

selfo 不把照片或视频上传到开发者控制的境外服务器。但 Apple Maps、App Store、iCloud、GitHub Pages 和 Gmail 可能根据其全球基础设施在你所在国家或地区以外处理相应坐标、交易状态、网站日志或支持邮件。

对于中国大陆用户，相关处理是否构成个人信息出境以及需要履行的告知、同意或评估程序，取决于具体数据、服务角色和适用法律。适用法律要求时，我们会在相关处理发生前另行履行必要程序。本政策不替代依法需要的单独同意。

8. 本网站的访问数据

本网站是托管在 GitHub Pages 上的静态站点。开发者没有加入自建分析、广告、Cookie 画像、登录、支付或上传表单。

GitHub 表示，无论访客是否登录，访问 GitHub Pages 时都会为安全目的记录并存储访客 IP 地址；GitHub 还可能依据其隐私声明处理设备与浏览器信息、请求时间、访问页面、来源页面和链接交互等使用信息。来自中国大陆的访问连接信息可能在境外处理。详情见 GitHub Pages 数据收集说明和 GitHub 隐私声明。

9. 未成年人

selfo 不专门面向 13 周岁以下儿童，也不面向中国大陆 14 周岁以下未成年人提供专门服务。未成年人应在父母或监护人的同意与指导下使用。如果监护人认为未成年人向我们发送了个人信息，请通过邮箱联系，我们会核实并按适用法律处理。

10. 政策变更与联系

如果功能、数据处理或法律要求发生变化，我们会更新本政策及页面顶部日期。重大变更会在 App 内、版本说明或本网站以合理方式提示；适用法律要求重新同意时，我们会另行取得同意。
